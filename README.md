# Rife Free child theme with Tainacan support
[![Project Status: Inactive – The project has reached a stable, usable state but is no longer being actively developed; support/maintenance will be provided as time allows.](https://www.repostatus.org/badges/latest/inactive.svg)](https://www.repostatus.org/#inactive)

This is a child theme of [Apollo13's](https://apollo13themes.com) [Rife Free](https://wordpress.org/themes/rife-free/) that offers Tainacan items list support and some adjustments made exclusevelly to the Sala de Situação project.
